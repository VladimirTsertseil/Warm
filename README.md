# Warm — GitHub Pages

Готовая статическая версия Warm 5.0.1 с интерфейсом Warm 3.6 и проверенным движком V5. Расчёт выполняется в браузере через Web Worker; локальный Node.js-сервер не нужен. Экспериментальные файлы V6 в публикацию не входят.

## Публикация

1. Распакуйте `Warm_GitHub_Ready.zip`. В корне распакованных файлов должен лежать `index.html`.
2. Откройте свой GitHub-репозиторий, загрузите все файлы и папку `engine-v5` в корень и сохраните изменения.
3. В репозитории откройте **Settings → Pages**. В разделе публикации выберите ветку `main` и папку `/(root)`, затем сохраните.
4. Откройте адрес Pages, например `https://USERNAME.github.io/Warm/`.

Пути к скриптам, стилям и worker относительные, поэтому приложение рассчитано и на размещение в подпапке репозитория. Для проверки можно открыть `index.html` через статический HTTP-хостинг. Запускать локальный Node-сервер для публикации не требуется.

## Возможности

- Рисование ортогональной комнаты и редактирование формы.
- Добавление препятствий и выбор положения коллектора на стене.
- Настройка шага трубы, диаметра, отступов, радиуса изгиба и максимальной длины контура.
- Автоматическое построение V5, отображение результата, ручная правка и сохранение схемы в браузере.

## Ограничения

У сложных помещений поиск может завершиться по ограничению времени без проверенной раскладки. В частности, для сохранённого сложного H-образного примера известен `SEARCH_LIMIT`; результат в таком случае не создаётся. Это поведение не исправлялось при подготовке Pages-пакета.
