Warm 3.5.0 — обновление

1. Распакуйте ZIP.
2. В GitHub откройте Add file → Upload files и загрузите содержимое распакованной папки в корень репозитория. index.html должен быть в корне, без папки Warm-main вокруг него.
3. Сохраните загрузку и дождитесь обновления сайта.
4. Если видна старая версия, откройте force-update.html на своём сайте и нажмите «Открыть Warm».

Работа: задайте размеры и форму → выберите сетку 100, 150 или 200 мм → установите коллектор → нажмите «Создать».
Число контуров, зоны и повороты подбираются автоматически. Полные длины до 80 м включают оба подвода и дуги. Длины каждого контура показаны под выбором сетки.
«Правка» изменяет готовый результат. «Раскладка» показывает подробности и прежние способы расчёта.

Файлы на GitHub автоматически не изменялись. Исходный пользовательский ZIP сохранён.
