# Warm

**Warm** — веб-приложение для проектирования раскладки труб водяного тёплого пола в помещениях простой и сложной формы.

Текущая версия: **3.1.0 — улитка по монтажной сетке**
Демо: https://vladimirtsertseil.github.io/Warm/

> Проект находится в активной разработке. Расчёт помогает подобрать геометрически допустимую трассу трубы, но не заменяет теплотехнический и гидравлический расчёт системы отопления.

В 3.1 добавлена рабочая улитка по монтажной сетке 100/150/200 мм: прямые участки
привязаны к направляющим, повороты представлены круговыми дугами. Радиус задаётся
вручную, шаг — целым числом ячеек. Поддерживаются трубы 16/17/20 мм; диаметр не
определяет радиус автоматически. Редактор формы сохранён.

Результат 3.1 — **одна рабочая улитка без подводов к коллектору**. Подводы и двойная
змейка относятся к этапу 3.2, несколько сеточных контуров — к 3.3, их ручная правка —
к 3.4. Прежние методы и ручная труба доступны через «Прежний расчёт».

Установка патча: [UPDATE-3.1.txt](UPDATE-3.1.txt). Устройство и проверки 3.1:
[docs/WARM-3.1.md](docs/WARM-3.1.md). Аудит и общий план:
[docs/WARM-3-PLAN.md](docs/WARM-3-PLAN.md).
В аудите отмечены два воспроизводимых сбоя прежних тестов; полный набор пока не зелёный.

## Возможности

- создание помещения из прямоугольника с угловыми вырезами;
- добавление препятствий и исключённых зон;
- ручное редактирование геометрии;
- выбор положения коллектора;
- смена направления подачи и обратки;
- настройка монтажной сетки, диаметра, шага проходов, радиуса и отступа;
- рабочая улитка по сетке, проверка прямых и дуг на пересечения и выход за границы;
- длина с учётом дуг, предупреждение свыше 80 м без автоматического разбиения;
- сохранение и повторная проверка улитки при открытии, экспорт PNG;
- прежний расчёт 2.x со змейками, несколькими контурами и ручной правкой;
- локальное сохранение схем и прежних ручных черновиков.

## Как пользоваться

1. Создайте новое помещение и задайте его размеры.
2. При необходимости добавьте угловые вырезы и препятствия.
3. В параметрах выберите монтажную сетку и диаметр трубы.
4. Нажмите **«Улитка»**, укажите радиус поворота, шаг в ячейках и отступ.
5. Нажмите **«Построить улитку»**. На плане появится проверенная рабочая часть;
   её длина указана без подводов. Если вариант не найден, приложение сообщает об этом.
6. В параметрах сохраните схему или экспортируйте PNG. Для прежнего режима выберите
   **«Улитка → Прежний расчёт»**; ручная правка доступна для прежних маршрутов.

Если приложение не может построить вариант, это означает, что допустимая трасса не найдена в текущем наборе вариантов и при текущих параметрах. Это не всегда означает, что физически уложить трубу невозможно.

## Запуск локально

Warm — статическое приложение на HTML, CSS и JavaScript. Сборка проекта не требуется.

Из-за использования Web Worker приложение лучше открывать через локальный HTTP-сервер, а не напрямую через `file://`.

Например, с Python:

```bash
python -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000/
```

## Публикация на GitHub Pages

Для обычной публикации репозитория:

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите публикацию из ветки.
3. Выберите ветку `main` и каталог `/ (root)`.
4. Сохраните настройки.

Главной страницей служит `index.html`.

Если браузер продолжает показывать старую версию после обновления файлов, можно один раз открыть `force-update.html`.

## Тесты

Для основных тестов нужен **Node.js 22+**:

```bash
node --test tests/engine.test.cjs tests/editor-core.test.cjs
node --test tests/grid-core.test.cjs tests/spiral-core.test.cjs
```

Для браузерных тестов дополнительно нужен Playwright:

```bash
npm install --no-save playwright@1.62.1
npx playwright install chromium
node tests/browser.cjs
node tests/mobile-editor.cjs
node tests/notifications.cjs
node tests/columns.cjs
node tests/grid-browser.cjs
node tests/spiral-browser.cjs
```

Те же основные проверки запускаются через GitHub Actions.

## Что проверяет расчёт

Новое ядро `spiral-core.js` проверяет непрерывность, привязку направляющих к сетке,
нахождение прямых и дуг в доступной зоне, отсутствие самопересечений и длину с
учётом дуг. Изолированные части комнаты не пропускаются. Проверка покрытия
геометрическая: каждый доступный узел выбранного шага должен иметь проход рядом.
Она не является теплотехнической оценкой.

Старый движок `engine-unified.js` используется для прежних методов. Он проверяет,
что построенная трасса:

- остаётся внутри доступной площади помещения;
- не проходит через препятствия;
- не имеет недопустимых пересечений;
- сохраняет непрерывность контуров;
- учитывает минимальный радиус поворота;
- не превышает заданную максимальную длину контура;
- корректно соединяется с подачей и обраткой коллектора.

После этого допустимые варианты сравниваются по качеству покрытия, равномерности шага, балансу контуров и удобству трассировки.

## Ограничения

Сейчас Warm **не выполняет**:

- расчёт теплопотерь помещения;
- подбор температуры теплоносителя;
- гидравлическую балансировку;
- подбор насоса, коллектора или смесительного узла;
- автоматическую проверку строительных норм конкретной страны;
- полноценный CAD/BIM-экспорт.

Очень сложная геометрия, узкие проходы, большое количество препятствий или слишком строгие ограничения длины могут привести к тому, что автоматический вариант не будет найден.

## Данные

Черновики и состояние ручного редактора сохраняются локально в браузере. Серверная база данных для пользовательских проектов сейчас не используется.
