Warm 2.6.1 — дополнительное обновление редактора

Устанавливается ПОВЕРХ уже установленного hotfix для двух препятствий.
Просто замените одноимённые файлы в корне репозитория файлами из этого архива.

Что изменено:
- Нижняя панель правки: Двигать / Ластик / Рисовать / Ещё.
- Ластик выбирает любые две точки на одном контуре, в том числе посередине прямого участка.
- Участок между точками А и Б визуально удаляется.
- После выреза редактор автоматически переходит в свободное рисование.
- Новый участок можно провести пальцем или мышью от А к Б; конец примагничивается к Б.
- Рисование можно продолжать несколькими движениями, сбросить и нарисовать заново.
- Undo/Redo учитывает вырез и ручное рисование.
- Закреплённые участки ластик не удаляет.
- Проверка H1–H7 сохраняется: новый ручной участок проверяется как обычная труба.
- Старый автоматический «Обход препятствия» не удалён — перенесён в меню «Ещё» → «Автообход».

Проверено:
- JavaScript syntax check: OK.
- Node regression tests: 13/13 passed (включая предыдущий кейс с двумя препятствиями).
- Headless Chromium smoke-load: без SyntaxError / ReferenceError / TypeError.
